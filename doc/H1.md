2. 重点工作目标与关键动作
   以上重点工作在过去半年的核心目标是什么？采取了哪些关键策略或关键动作？

2.1 导入，compaction，schema change的锁冲突，导致导入失败
- 关键动作
    - 【mow减少锁冲突专项】
        - 发现锁冲突有相当一部分原因是冲突后 sleep 重试，持有了锁被占用的时间
        - 修改原来锁的 kv 设计，减少了不必要的锁冲突
        - 兼容升级，防止升级过程中产生正确性问题花了较多的时间思考
2.2 Delete bitmap数量多、数据量大，对 ms 造成了很大的压力
- 关键动作
    - 【减少delete bitmap 专项】
        - 在compaction时合并部分delete bitmap，减少ms中的delete bitmap的数目
        - 同时，该方案也减少了 be 内存中的 delete bitmap 数目，会降低 be agg delete bitmap 对 cpu 的消耗
    - 【delete bitmap v2存储专项】
        - 重新设计 delete bitmap 的存储方式，大的delete bitmap存到对象中；
        - 由每次可能写入多个delete bitmap 的 kv，改成只写入一个 kv；
        - 同时，新的方式存储兼容了快照工作

    - 不足：
